# Unit Converter 

Uma ferramenta de conversão de unidades prática, leve e responsiva criada para converter valores de comprimento, massa e temperatura.

##  Funcionalidades

- Conversão dinâmica em tempo real (sem precisar recarregar a página).
- Suporte para Comprimento (m, km, cm, mi), Massa (kg, g, lb) e Temperatura (°C, °F, K).
- Interface moderna em Dark Mode.

##  Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
